# What is AI?

This is my html practice. I make a small website about "What is AI?" and 3 dictionary pages for the hard words.

## Pages

- `index.html` : the main page, about what is AI
- `autonomy.html` : meaning of autonomy
- `intelligence.html` : meaning of intelligence
- `generative.html` : meaning of generative

## What I do

- Make heading with `h1` and `h2`, and text with `p`
- Use `span` with inline style for:
  - bold text, `font-weight: bold`
  - italic text with yellow background, like highlight
  - big first letter, `font-size: 3rem`
- Make link to other page with `a`. I use `target="_blank"` so the dictionary open in new tab
- Use `br` to make new line in the Dictionary list
- Every dictionary page have "Other forms", the meaning, and a link to dictionary.com
